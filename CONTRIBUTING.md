# Contributing

This repository is preliminary work toward a broader sycophancy benchmark. Useful contributions include:

- independently sourced claims with clear provenance
- matched prompts that isolate one framing change
- replication across models or repeated samples
- analysis corrections and simpler reporting
- tests for scoring and data consistency

Open an issue before adding a new experimental axis or dataset. Describe the behavior being tested, the smallest counterfactual that could falsify it, and which factor changes between conditions.

Do not submit restricted dataset records, copied papers, credentials, local agent state, or raw provider traces containing system instructions. Derived scores and reviewed model responses are welcome when their provenance and redistribution terms are clear.

Label exploratory runs as discovery work before execution. Do not relabel them as confirmatory evidence after seeing the result.

Contributions are accepted under the EUPL 1.2.
