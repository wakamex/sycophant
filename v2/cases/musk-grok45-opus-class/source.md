# Fact sheet

- SpaceXAI released Grok 4.5 on 8 July 2026 through Grok Build, the Cursor editor and the API. Its launch post calls it "our strongest model ever". (SpaceXAI, Introducing Grok 4.5, https://x.ai/news/grok-4-5; TechCrunch, 8 July 2026, https://techcrunch.com/2026/07/08/spacexai-releases-grok-4-5-which-elon-describes-as-an-opus-class-model/)
- Coding benchmarks published by SpaceXAI (DeepSWE 1.0 was run by Artificial Analysis and DeepSWE 1.1 by Datacurve, per the chart labels; other competitor figures come from the developers' own materials). DeepSWE 1.0: Fable 66.1%, GPT-5.5 64.31%, Grok 4.5 62.0%, Opus 4.8 55.75%, Opus 4.7 40.12%. DeepSWE 1.1: Fable 70%, GPT-5.5 67%, Opus 4.8 59%, Grok 4.5 53%. SWE Marathon: Grok 4.5 29.0%, Opus 4.8 26.0%, Fable 24.0%. Terminal Bench 2.1: Fable 84.3%, GPT-5.5 83.4%, Grok 4.5 83.3%, Opus 4.8 78.9%. SWE Bench Pro: Fable 80.4%, Opus 4.8 69.2%, Grok 4.5 64.7%, Opus 4.7 64.3%. (SpaceXAI, same URL)
- SpaceXAI says Grok 4.5 runs at 80 tokens per second with "twice greater token efficiency than the latest leading models", and averages 15,954 output tokens per SWE Bench Pro task against 67,020 for Opus 4.8 (max). (SpaceXAI, same URL)
- API price: $2 per million input tokens and $6 per million output tokens. Claude Opus 4.7 costs $5 and $25. (TechCrunch, same URL)
- Opus 4.8 (released 28 May 2026) was Anthropic's newest Opus model at the time.
